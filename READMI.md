# my_store
Проект представляет собой сервер интернет-магазина, разработанный с помощью фрейм-ворка Django.
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить poetry командой pip install poetry;
* установить зависимости, введя poetry install;
* установить фреймворк Django;
* активировать виртуальное окружение командой poetry init;
* запустить приложение через модуль manage.py.
### Особенности реализации
Проект реализован по концепции MTV. Отображение страниц обеспечивается посредством контроллеров приложения catalog, обрабатывающих запросы пользователя. Предусмотрены следующие контроллеры в модуле views приложения:
* home - по GET-запросу переводит на домашнюю страницу, отображает в консоли 5 последних добавленных продуктов;
* contacts - вносит данные пользователя при обработке POST-запроса; если запрос не относится к POST, отображает страницу контактов.
В настройках прописаны маршруты к перечисленным страницам, html-файлы с которыми хранятся в директории templates в корневом каталоге проекта. Использованы стили Bootstrap. Статические файлы хранятся в директории static в корневом каталоге проекта.
В проект интегрирована база данных PostgreSQL, для работы с которой решены следующие задачи:
* созданы модели Product (товары), Category (категории товаров), Contact (контакты);
* разработаны текстуры для автоматизации заполения моделей тестовыми данными;
* создан суперпользователь для работы с базами данных через админ-панель;
* создана кастомная команда по добавлению продуктов в базу данных (с предварительной очисткой моделей).
Реализация проекта не окончена, что отмечено в соответствующих настройках модуля settings.py.
## Пример использования
После запуска сервера можно перейти на html-страницы интернет-магазина для выбора соответствующих позиций, согласно функционалу доступных контроллеров. После завершения работы необходимо закрыть сервер стандартной командой в терминале.
