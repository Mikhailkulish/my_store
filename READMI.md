# my_store
Проект представляет собой сервер интернет-магазина, разработанный с помощью фрейм-ворка Django.
## Установка и использование
Чтобы установить и запустить проект, нужно выполнить следующие действия:
* клонировать репозиторий, использовав ссылку с аккаунта GitHub;
* установить poetry командой pip install poetry;
* установить зависимости, введя poetry install;
* установить фреймворк Django;
* активировать виртуальное окружение командой poetry init;
* запустить приложение через модуль manage.py.
### Особенности реализации
Проект реализован по концепции CRUD. Отображение страниц обеспечивается посредством контроллеров приложения catalog и blog с отображением страниц магазина, отдельного раздела с блогом, интегрированного в общую концепцию проекта. Реализована возможность просмотра, добавления, обновления товаров в каталоге (в том числе через формы для пользователей), с валидацией вносимых данных, стилизацией форм. Разработаны отображения для операций с постами в блоге через html-шаблоны.
В настройках прописаны маршруты к перечисленным страницам, html-файлы с которыми хранятся в директории templates в корневом каталоге проекта. Сделаны базовые шаблоны и подшаблоны для оптимизации кода html-страниц в каждом из приложений. Использованы стили Bootstrap. Статические файлы хранятся в директории static в корневом каталоге проекта. Реализованы медиа фильтры для отображения в шаблонах фото товаров каталога и изображений с превью постов блога.
В проект интегрирована база данных PostgreSQL, для которой реализованы следующие задачи:
* созданы модели Product (товары), Category (категории товаров), Contacts (контакты) для приложения Catalog, Post (посты) для приложения Blog;
* разработаны текстуры для автоматизации заполнения моделей тестовыми данными;
* создан суперпользователь для работы с базами данных через админ-панель;
* создана кастомная команда по добавлению продуктов в базу данных (с предварительной очисткой моделей).
Для регистрации и авторизации пользователей создано отдельное приложение users. Возможность добавления, редактирования, удаления товаров, просмотра подробной информации о товарах доступна исключительно зарегистрированным и авторизованным пользователям. На электронный адрес зарегистрировавшегося посетителя направляется приветственное письмо.
Распределены роли пользователей для ограничения прав на добавление, редактирование удаление товаров.
Реализовано кеширование для ускорения работы сайта. Предусмотрена возможность отображения доступных категорий товара, с выбором списка по заданной пользователем позиции.
Реализация проекта не окончена, что отмечено в соответствующих настройках модуля settings.py.
## Пример использования
После запуска сервера можно перейти на html-страницы интернет-магазина для выбора соответствующих позиций, согласно функционалу доступных отображений. После завершения работы необходимо закрыть сервер стандартной командой в терминале.
